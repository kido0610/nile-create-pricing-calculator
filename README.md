# 料金・採算・ROI計算ツール

`/pricing-calculator` は、営業ヒアリングから案件診断、工数見積もり、適正プラン・価格、採算、顧客ROI、提案文、実績記録までを扱う社内用ページです。

## 起動とテスト

```bash
pnpm dev
pnpm test:pricing
```

## ファイル構成

```text
calculations.ts  # 料金・分配・ROI計算
estimator.ts     # 工数見積もり基準時間と計算
sales-diagnosis.ts # 営業診断、機能別工数、プラン提案、営業コメント、ダッシュボード
page.tsx         # UI、端末内保存、JSON/CSV、ブラウザ印刷によるPDF見積書
page.module.css  # PC・モバイル表示
```

## 計算の順序

1. 税抜売上は税込売上を1.1で割り、四捨五入して円単位にする。
2. 直接費、共通経費、事業留保を順に控除する。
3. 選択した分配方法を適用し、残額を木戸・みひとの割合で分配する。割合合計が100%でない場合は分配を確定しない。
4. 顧客の実質月間削減時間は、削減時間へ効果実現率を掛けて求める。月間純便益は月額料金と顧客の月額外部費用を控除する。
5. 3年間ROIは、3年間累積純便益を3年間投資額で割る。

## 営業フロー

1. **案件診断**で会社・現状業務・必要機能・難易度をヒアリングする。
2. 機能別の基準時間、要件整理、テスト、導入、修正、30〜50%のバッファから最短・標準・安全工数を算出する。
3. 安全工数と設定済みのプラン境界から、お試し／梅／竹／松／完全オーダーを提案する。
4. 「工数・プランを料金計算へ反映」で初期構築予定時間、税込価格、顧客の現在工数を料金計算へ入れる。
5. 提案コメントをコピーし、必要なら「見積書をPDF保存」からブラウザの印刷画面でPDFを保存する。

## 計算式

- 診断の開発工数＝選択機能の基準時間の合計。安全工数＝標準工数＋標準工数×不確実性バッファ（30〜50%に制限）。
- 税抜売上＝税込売上÷1.1を四捨五入。直接費 → 共通経費 → 事業留保 → 選択した分配方法の順に計算する。
- 実質月間削減時間＝月間削減時間×効果実現率。月間純便益＝月間削減額−月額料金−顧客の月額外部費用。
- 3年間ROI＝3年間累積純便益÷3年間投資額×100。

基準時間とプラン境界は画面の「設定」で変更でき、同じブラウザのlocalStorageに保存されます。工数・ROIは確定値ではなく、正式見積前に要件・連携仕様・データ状態を確認するための補助値です。案件と実績も端末内のlocalStorageに保存されるため、必要な案件はJSONダウンロードで控えを残してください。
